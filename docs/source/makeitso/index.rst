Engage
========================

This page provides links to documentation for the ``engage.py``, ``makeitso.py`` and
``makeitso-gamhelio.py`` scripts, which simplify the process of configuring
and running MAGE and GAMERA-helio applications. ``engage.py`` is the entry
point for GR, GRT and GRX MAGE runs; ``makeitso.py`` can still be used
directly for a GR run.
