Rules of the Road
=================

* All users are strongly encouraged to contact the developers before
  publication or presentation of ``MAGE`` or other ``Kaiju`` results. The
  developers do their best to identify issues and bugs, but make no
  guarantees. The developers are happy to help the users learn how to
  apply the model correctly and interpret the results appropriately to
  ensure their scientific robustness.
* If you have a problem, please try to find the answer in this documentation (and `Google <https://google.com>`_).
* If you seek help in the ``#kaijuhelp`` Slack channel, please be patient and polite.
* If other users encounter issues you have already seen, try to help them.
* If you find an error in the documentation, please bring it to our attention in the ``#kaijuhelp`` Slack channel.
* Instructions for joining the ``#kaijuhelp`` can be found :doc:`here <index>`.
